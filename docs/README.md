# Documentação do My Easy Development System

O [GUIA_DE_USO.md](GUIA_DE_USO.md) é o ponto de entrada operacional: ambiente, projeto novo, especificação, roteamento, Gates, desenvolvimento, QA, segurança, feedback, continuidade, recuperação e validação de bootstrap em sessão limpa.

As fontes normativas permanecem [AGENTS.md](../AGENTS.md), [standards/](../standards/README.md) e [.agents/skills/](../.agents/skills/). Os [templates](../templates/README.md) apoiam o registro proporcional; não são formulários obrigatórios para toda tarefa.

O [README principal](../README.md) contém instalação rápida, primeiro uso e diagnóstico. O [verificador](../scripts/check.py) executa checagens locais e testes; a [cópia do harness](../scripts/copy_harness.py) prepara um projeto vazio sem depender de Git e recusa destinos ocupados. O guia detalha dependências, licenciamento das fontes copiadas e integração manual em projetos existentes.

## Estado das evidências da rodada 7.1

Este guia documenta o procedimento esperado; não constitui prova de execução pelo Codex. Uma cópia íntegra comprova preparação estrutural. Testes do laboratório comprovam somente o comportamento local que exercitam. Descoberta natural, observância das regras e uso efetivo de Skills exigem validação posterior em sessão nova.

O pacote histórico da rodada Gate A 7.1 foi registrado fora do repositório, com protocolo, matriz, brief mínimo, fixture sintética, baseline, diffs e evidências. Sua disponibilidade não foi reconfirmada; os caminhos antigos de ensaio foram retirados da documentação atual. Não presumir acesso a artefatos de outra sessão nem autorização de escrita em diretórios externos.

MEDS-009, MEDS-010, MEDS-014, MEDS-015, MEDS-039, MEDS-040 e MEDS-041 continuam pendentes de teste independente. Os seis marcos estruturais mantêm suas ressalvas; não há declaração de conformidade operacional integral.

Os identificadores MEDS usam a identidade atual e conservam os números históricos. O guia distingue trabalho no próprio repositório de cópia seletiva para outro projeto; ambos usam a raiz real escolhida, sem instalação em diretório obrigatório. A licença está em [LICENSE](../LICENSE).
