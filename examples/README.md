# Exemplos do MEDS

O [laboratório sintético](../codex_lab_5_5/ai_triage.py) exercita validação de entrada e saída, fallback e revisão humana obrigatória. Seus [24 testes](../codex_lab_5_5/test_ai_triage.py) usam callbacks locais, sem modelo, API, credencial ou custo externo.

O [Guia de Uso](../docs/GUIA_DE_USO.md) contém um cenário hipotético de painel local. Os [templates](../templates/README.md) incluem exemplos de preenchimento, com resultados a obter. Esses exemplos documentais não são aplicações prontas nem evidências de execução.

Projetos solicitados pelo usuário são criados em `workspaces/<slug>/`, conforme [AGENTS.md](../AGENTS.md). Não mover projetos para este diretório.
