# Legado documental de Skills

Esta pasta `skills/` é legado/documental. Não é o diretório runtime nem a fonte canônica das Skills do Évora Pulse Development System.

As 12 Skills canônicas estão em [.agents/skills/](../.agents/skills/), cada uma no formato `<nome>/SKILL.md`. Para seleção e uso, consultar [AGENTS.md](../AGENTS.md), o [Capability Routing Standard](../standards/capability-routing-v1.md) e o [guia operacional](../docs/GUIA_DE_USO.md).

Não criar cópias executáveis nesta pasta, não deduzir capacidades pela presença deste README e não ativar todas as Skills por padrão. Identificar propósito, superfície e risco, ler o procedimento pertinente na origem canônica e registrar evidências reais. Disponibilidade documental não comprova carregamento ou uso efetivo pelo Codex.
